## 2026-08-17：v2 重定位启动 + 首个纵向切片

**维护者反馈与决定（grilling 会话逐项拍板）**：v1.0.0 存在三点不足——受众太高级、可交互性太弱、缺优秀案例引用。决定：

1. **全面转型零基础**（D1）：主受众改为零基础网页学员，现有 26 课技术型内容下沉为进阶线，模块 0–3 入口与先修重写。`CONTEXT.md` 受众词条同步改为双词条（原词条的「避开零基础群众」由本决定废止）。
2. **BYO-key 浏览器直连**（D2，[ADR-0008](./adr/0008-byo-key-browser-direct-experiments.md)）：学员网页内输自己的密钥，浏览器直连 OpenAI/Anthropic 官方端点；密钥只存页面内存；离线演示模式为默认免费路径；不部署代理。
3. **证据闭环双轨**（D3）：起步章浏览器内验证；核心线保留 course_check 并重设计「我的进度」导入向导（维护者原话：现有证据导入「连我都看不懂」）。
4. **案例参考库**（D4）：superpowers/mattpocock/anthropics skill 的注释式导读附录页 + 课内嵌链接，只外链不复制。
5. 载体：[v2 总规格](./specs/agent-engineering-course-v2.md) + GitHub Issue；本次交付首个纵向切片。

**本切片交付**：W1 概念课（含浏览器知识检查组件 StartQuiz）、W3 API key 课（含 ByoKeyChat 双模式实验组件）、案例参考库页、v2 规格、ADR-0008、来源账本 9 条新登记（调研核验 2026-08-17）、契约测试 `test-byo-key.mjs` 与浏览器验证 `verify-start-lessons.mjs`（验证离线模式零外部请求）。设计借鉴调研结论：ed-donner guides 前置桥接、HF Unit 0 集中铺垫+免费默认、Microsoft 第一课纯概念起点。

**边界**：真实 API 调用无法入 CI（无密钥原则），CI 只验离线模式；BYO 真实调用属于学员现场验证项。版本仍为 1.0.0，v2.0.0 待 V2-1…V2-8 全部完成后发布。
