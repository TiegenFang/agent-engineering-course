## 2. 零基础网页学员旅程（最高层用户故事）

> 我只会用浏览器。我打开课程首页，第一课用生活化类比讲清「模型/对话/工具/Agent」；每课末尾的浏览器知识检查立刻告诉我懂没懂。学到 API key 那一课，我在页面里输入自己的密钥，第一次亲手调通一个真实模型对话，并明白密钥、费用和安全的关系。想继续深入时，网页告诉我装好终端环境能解锁什么，我顺着桥进入核心线，原来的技术型课程还在那里等我。

## 3. 网页端起步章结构（借鉴调研结论）

设计依据（2026-08-17 调研）：ed-donner/agents 的 guides 前置桥接层、HuggingFace Agents Course 的 Unit 0 集中铺垫 + 免费默认、Microsoft 课程第一课纯概念起点。

| 课节 | 主题 | 交互 | 验证方式 |
| --- | --- | --- | --- |
| W1 | 什么是 Agent：模型、对话、工具 | 浏览器知识检查（3 题，即时反馈） | 浏览器内完成状态 |
| W2 | 与模型对话的正确姿势：把话说清楚 | 输入改写练习（对照模糊/清晰指令） | 浏览器内完成状态 |
| W3 | API key 是什么 + 第一次真实调用 | BYO-key 对话实验（离线演示/真实调用双模式） | 浏览器内完成状态 + 现场调用记录 |
| W4 | 从网页到终端：解锁 Codex 与核心线 | 桥接检查清单（自评 + 引导安装） | 引导至模块 0 |

免费路径：W1–W4 全部可零费用完成（W3 离线模式即可拿到完成状态；真实调用为可选付费增强）。

## 4. 现有内容迁移

- 模块 0–12 的 26 个课节**不重写内容**，统一挂「进阶线」标识；先修关系入口改为「完成 W4 或已具备终端/Git 基础」。
- 首页课程壳改为零基础优先的叙事：先展示起步章入口，进阶线折叠其后。
- 证据双轨：起步章完成状态存浏览器本地（现有本地学习记录机制）；核心线继续 `course_check` → 匿名 JSON，但新增「我的进度」向导页（普通话解释证据文件是什么、逐步引导、失败原因自动诊断）。

全部进入来源账本；不复制任何正文或代码。

## 6. 范围边界（不做）

- 不做代理服务器、账号系统、云端学习状态（维持 ADR-0004）。
- 不复制第三方课程正文或 skill 实现；案例只做导读与映射。
- 不降低现有核心线的技术深度；零基础转型通过「起步章 + 入口重排」实现，不通过删减核心内容实现。
- 不在 CI 中真实调用付费 API；真实调用永远是学员本机的现场验证项。
