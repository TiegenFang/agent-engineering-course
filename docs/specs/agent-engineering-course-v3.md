## 0. 背景与北极星

v2.0.0 落地了零基础重定位的骨架（四课正文、四个交互组件、BYO-key 实验、案例库、进度向导），但评估结论是「可交互教程」目标最多完成三分之一：招牌主线（真实调用）被门槛挡住且离线兜底是预制串；四个交互里只有一个有真反馈；完成状态不闭环、不诚实（W3 零落盘、W2 闭眼勾选也算完成、W4 不校验前置）。

**v3 北极星（所有改动的验收标尺）**：

> 一个从未碰过终端和 API 的人，能**在不看答案的情况下**：说出模型与 Agent 的区别；写出一条四要素指令；看懂一次真实调用里「线上发生了什么」；并明确知道自己下一步去哪。

执行原则：**证据先行、插画包壳**——先让数据与反馈真实，再用插画承载它们；绝不反过来。

## 2. 零基础学员旅程（最高层用户故事，v3 版）

> 我只会用浏览器，也从没碰过 API。我跟着一位圆头圆脑的小向导，在 W1 点击跑完一圈 Agent 循环——每站先猜再看答案；在 W2 亲手把一句模糊指令拖成四要素结构，向导收到模糊指令时原地打转的样子让我笑出了声；在 W3 看着一个贴着 token 标签的包裹替我跑完一次真实调用的全程——没有密钥，我看到的也是真实记录的数字；如果我愿意，输入自己的密钥，动画回放的就是我刚才那一次调用。四枚脚印点亮，终端之门打开，小向导把工具箱递给我，页面也换回了工程师的样子。我的每一步都被浏览器记住，还能打包带走。

免费路径不变：W1–W4 全部零费用可完成（W3 看完真实样例即算；真实调用为可选付费增强）。

## 3. 逐课改造（v2 现状 → v3 目标）

| 课节 | v2 现状 | v3 改造 | 完成判定（v3） |
| --- | --- | --- | --- |
| W1 | 3 道一次性单选，答错只给解释 | **循环跑道**：小循在四站点环形跑道（输入→生成→调工具→观察决定），点击推进、每站普通话解释；跑前 2 道**预测题**；支持重做与错题回顾 | 预测作答 + 跑道完整跑一圈 + 知识检查通过 |
| W2 | 改写 + 单框「我覆盖了四要素」自评 | **指令小剧场**：模糊/结构化指令双分镜动画 + 四要素卡片**拖拽配对**；自证改**引用式**（四要素各指出落点） | 两轮改写 + 四要素各引用一句 + 自评 |
| W3 | 离线=预制串；真实调用成功不落盘 | **请求之旅（旗舰）**：包裹穿 HTTPS 隧道到服务商大楼（验钥匙+计费关卡）；离线挂载**真实样例数据**，真实模式**回放学员实调数字**；错误分支动画 + 普通话提示；无密钥路径 + 可选账户引导 | 离线看完真实样例，或真实调用成功一次（含匿名摘要落盘） |
| W4 | 6 项勾选即「起步章完成」，不校验前置 | **分岔地图**：插画地图嵌 W1–W4 聚合进度脚印，四枚齐了「终端之门」才亮；小循交接工具箱、画风渐变回编辑风；清单条目修订（区分「理解」与「意愿」） | W1–W3 四键齐全 + 本页勾选 |

## 4. 进度与证据模型

- **共享进度模块**（V3-1 落地）：统一读写 `course-start-progress`，消除 `StartQuiz`/`DialogueRewrite`/`TerminalBridge` 三处硬编码；W3 经此模块落盘 `start-3` 与匿名调用摘要。
- **聚合展示**：每课顶部粘性进度条（`W1✓ W2✓ W3⬜ W4⬜`）+ W4 地图脚印 + 首页总览。
- **可携带**：起步章进度支持导出/导入 JSON，与进阶线 `EvidenceLoop` 的导入机制并列；首页「我的进度」一处同呈两段旅程，`ProgressWizard` 第 0 步补衔接语。
- 键盘操作等价：拖拽配对必须有键盘替代路径；所有动画在 `prefers-reduced-motion` 下为静态分帧 + 「下一帧」按钮，并有 `aria-live` 文字播报。

## 5. 视觉系统摘要（详见可视化方案计划）

- 主角小循：中性、无性别年龄指向、青绿主色（同源 `#087f68`）、5 种基础表情姿态；纯仓内 SVG，一处定义四课复用。
- 叙事红线：小循只引导、不陈述产品事实；不给 Codex/Claude Code 画拟人化身；不画假产品 UI。
- 设计增补：插画层专用色板/描边/面积预算（单课插画 ≤ 首屏 40%）并入 t03 设计文档；许可证仓内原创 CC BY 4.0，入来源账本。

## 6. 范围边界（不做）

- 不改模块 0–12 任何内容；不做整站 rebrand。
- 不做积分、徽章、打卡、排行榜；不做音效；不做自动播放长动画。
- 不引入 Lottie/游戏引擎等新运行时依赖；不引入 AI 生成插画或第三方 IP 素材。
- 不做文本启发式判分（对初学者误判比不判更糟）。
- 不做代理服务器、账号系统、云端学习状态（维持 ADR-0004/0008）。
- 不在 CI 中真实调用付费 API；真实调用仍是学员本机现场验证项。
- 不动 checker：v3 全部改动在 `site/`，`course_check` 及其测试仅回归验证。

## 8. 发布门槛（v3.0.0）

1. **最高接缝**：全新浏览器 profile 实走 W1→W4——预测作答、跑道跑圈、拖拽配对、看完真实样例、四键全绿、脚印点亮、进度导出后换浏览器导入成功。
2. **无障碍复审**（WCAG 2.2 AA，重点新增）：动画的键盘等价操作、reduced-motion 静态分帧、`aria-live` 播报、插画内文字对比度与文本替代。
3. **移动端**：至少一台移动浏览器实走全程；BYO-key 的 fetch/CORS 真机验证。
4. **回归**：现有 CI 全绿；checker 测试不改不破。
5. **现场验证**：至少一次真实调用抽查，如实记录客户端、模型、日期、成本边界；W3 样例数据的采集过程与脱敏说明入来源账本。
6. **worklog + tag**：工程决定与验证证据记录 worklog.md，发布 tag `v3.0.0`。
