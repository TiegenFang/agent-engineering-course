# ADR-0009: 教学插画层只解释概念，不模拟产品 UI；吉祥物只做向导，不做事实来源

日期：2026-08-17
状态：已接受（维护者于 2026-08-17 批准 v3 起步章交互深化总规格，含第 10 节全部默认建议；本 ADR 落实其中 D2）

## 背景

v2.0.0 发布后的评估结论是网页端起步章（W1–W4）可交互性不足：零基础学员需要友好、有隐喻、有情绪安全感的学习界面。同时，既有设计规范已经固化了两条约束：

1. `docs/design/t03-brand-spec.md` 的 UI/图片策略写明「不用 CSS 剪影、手绘 SVG、stock photo、生成插画、假终端或假 dashboard **替代真实产品界面**」，并在禁区中禁止 emoji 图标与「生成插画替代真实产品界面」。
2. 课程的可信度契约要求证据先行语气：产品事实（价格、版本、限额、行为）只能来自官方文档与现场核验，由正文承载。

「给起步章加插画」若解释不当，会同时撞上这两条约束：插画一旦画出 Codex/Claude Code/服务商控制台的「界面」，就违反 t03 禁令并虚构产品行为；吉祥物一旦开口陈述产品事实，就把易变信息的真源从官方文档转移到了角色台词。

`t03-brand-spec.md` 禁令的宾语是「**替代真实产品界面**」——它并没有禁止一切插画。本 ADR 对这一条款作出**解释性收窄**并记录理由，避免未来贡献者要么误判「任何插画都被禁止」，要么反向越界「画个假产品界面也算插画」。

## 决定

课程成立一个**教学插画层**，边界如下：

1. **插画只用于解释概念，从不模拟产品 UI。** 允许用插画表达的对象是厂商无关概念：Agent 循环、一次请求的旅程、指令的四要素结构、从网页到终端的转折。禁止用插画、CSS 剪影或任何绘制手段复现、模仿或「示意」Codex、Claude Code、OpenAI/Anthropic 控制台或任何服务商产品的界面、终端输出或 dashboard；需要展示真实界面的场合，仍按 t03 规范走官方许可与来源账本流程。
2. **吉祥物（小循）只做向导，不做事实来源。** 小循可以引导节奏（「我们来看看下一步」）、表达情绪安全感，但不得陈述价格、版本、限额、速率等易变产品事实（不得说「OpenAI 的价格是 X」）。所有事实仍由正文以证据先行语气承载并标注来源与核验日期。
3. **不给 Codex、Claude Code 或任何第三方产品画拟人化身。** 第三方产品人格化有暗示背书的风险，与 t03「不暗示赞助、合作或背书」冲突。插画角色只代表课程与学员自身（小循是「实习生」，不是任何产品）。
4. **插画层资产为仓内原创 SVG。** 不引入 AI 生成插画（许可归属不清）、素材站资产（许可混杂）或任何第三方 IP 角色的化用与致敬改名；不用 emoji 图标。角色与场景随内容以 CC BY 4.0 发布、组件代码以 MIT 发布，登记入来源账本。
5. **对 t03 规范的解释性收窄**：t03「不用手绘 SVG/生成插画……替代真实产品界面」理解为——禁令针对「以绘制物冒充产品界面」，不禁止不模拟产品界面的概念解释插画。收窄仅此一条，t03 的其余禁区（emoji 图标、紫色渐变、圆角卡片左彩边、虚构 stats/testimonials、CSS/SVG 冒充产品截图）在插画层同样全部有效。
6. 插画层的具体设计语言（同源色板、描边基准、面积预算、静态等价物、`prefers-reduced-motion`、`aria-live` 播报、排印与许可证）由 `docs/design/v3-illustration-design-spec.md` 承载；该 spec 从属于本 ADR 的边界。
7. **作用范围**：插画层只作用于网页端起步章（W1–W4）及首页进度视图，模块 0–12 进阶线维持 Editorial 编辑风不变；W4 完成向编辑风的过渡衔接（「风格随能力成长」，v3 规格 D3）。

## 备选方案与取舍

- **不做插画层（字面执行 t03）**：规范风险为零，但 v2 评估显示零基础学员在纯编辑风界面中缺乏情绪安全感和概念锚点，v3 北极星（说出模型与 Agent 的区别等）缺乏承载形式；且 t03 禁令本意是防「冒充产品界面」，不是取消一切图示。
- **引入 AI 生成插画或动漫素材站资产**：表现力即时可用，但许可归属与第三方 IP 风险直接违反 ADR-0003/0005 与 t03 禁区，否决。
- **放宽为「可以画产品界面的风格化示意」**：被否决。一旦允许「示意产品 UI」，插画与假冒产品数据的边界将不可审查；保持「概念插画 / 产品事实」的硬边界使代码评审只需要检查「插画是否画了界面」，可执行性强。
- **几何极简而非手绘路线**（v3 规格第 10 节拍板）：小循与配角全部由纯几何形状拼装、可完全由代码生成与审查，无手绘带宽依赖，保留未来升级到手绘或 Lottie 的空间（Lottie 仍按视觉计划第六节暂不采用）。

## 后果

- 代码评审与内容契约获得一条可执行的检查规则：任何插画（SVG/绘图）出现产品窗口、终端、dashboard 形状，或吉祥物台词出现具体价格、版本、限额，即违反本 ADR。
- `t03-brand-spec.md` 继续作为产品 UI 模拟禁令的真源；本 ADR 与 `v3-illustration-design-spec.md` 只在其上叠加插画层的正向许可与设计约束。两者冲突时，以更严者为准。
- 插画层组件（`site/src/components/mascot/`）让 W1–W4 组件复杂度上升，后续每个动画课节必须同时维护动画逻辑与静态等价物（reduced-motion、noscript、打印），这是接受的维护成本。
- 若未来维护者希望让插画出现在进阶线（模块 0–12），需修订本 ADR 第 7 条，不得在实现中顺手扩展。
