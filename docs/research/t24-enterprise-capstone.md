# T24 企业核心结课轨道研究记录

## 结论

T24 将企业结课轨道收束为一条可核验的 Issue-to-PR 工作流：Issue 澄清、Context、Memory、Skill、MCP 权限边界、变更、测试、评审、交付和迁移挑战都必须留下状态证据。实验使用合成设备遥测与报告工具，不把企业数据、GitHub 记录、模型输出或真实账单送入课程检查器。

## 采用边界

- T16、T17、T20 和 T22 提供 Context/Memory/Skill/MCP/多 Agent 的前置能力；T24 只消费其稳定概念，不复制前置课节。
- 企业轨道与科研轨道共享公共评分维度：问题定义、上下文质量、操作安全、验证证据、可复现性、迁移能力和交付清晰度。
- `feature-issue` 是主路径，`bug-fix` 是变化输入迁移；固定状态数字是教学夹具，不是实际模型 Token、墙钟时间或企业 SLA。
- 正式客户端、真实 MCP、GitHub 权限、评审流程、身份治理和付费 API 属于后续现场核验，不由离线 fixture 代替。

## Evidence 设计

匿名证据只包含固定 lesson ID、课程版本、日期、检查 ID、布尔状态、变化输入和故障枚举。Checker 会根据故障与输入重新推导结果，并拒绝明显敏感字段。页面下载由学习者显式触发，学习记录仅在浏览器本地保存。
