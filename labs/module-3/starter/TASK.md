# 任务：修复设备遥测报告的单位归一化

## 背景

`data/readings.csv` 是公开合成数据，不代表真实设备。报告工具需要把摄氏度和华氏度统一为摄氏度，并忽略无法解析的时间戳、数值和不支持的单位。

## 目标

修复 `src/telemetry_report.py`，让已有测试和报告命令通过；保持报告 JSON 的字段结构，不把原始记录复制进报告。

## 非目标

- 不引入网络、数据库、第三方服务或真实设备连接。
- 不修改 `tests/` 来绕过失败，不改 `data/readings.csv`，不添加凭据。
- 不提交或推送，除非人工在审阅 diff 后明确决定。

## 验收标准

1. 不支持的单位、非法时间戳和非法数值会被忽略。
2. `F` 按 `C = (F - 32) * 5 / 9` 转换，输出保留稳定的 `mean_celsius`。
3. 测试通过，报告命令生成 `artifacts/report.json`，且报告不含 `timestamp` 或原始行列表。
4. `git diff --check` 通过，diff 仅涉及允许的源文件和 `worklog/` 记录。

## 故障注入

基线测试预期失败：这是已知缺陷的证据，不要直接删除测试。修复后重新执行测试，并在 `worklog/recovery.md` 记录失败原因、最小修复和恢复命令。
