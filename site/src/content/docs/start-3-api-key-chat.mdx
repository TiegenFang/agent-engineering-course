# W3 · API key 与第一次真实调用

前两课你只在网页内学习，零费用。本课第一次接触「程序世界的水电表」——API key。**不办密钥也能完成本课**（用离线演示模式），真实调用是可选的付费增强。

## API key 是什么

API key 是一串像 `sk-abc123...` 的密钥，作用类似「带计费的钥匙」：

1. **证明是谁在调用**：服务商据此把请求记到你的账户。
2. **按用量扣费**：不是订阅制门票，而是水电表——用多少算多少。一次演示对话通常只花不到一分钱，但你要有这个意识。
3. **必须像钥匙一样保管**：泄露的 key 等于别人用你的水电表消费。公共电脑不输入、不截图、不把 key 发给任何人（包括 AI 对话框）、不提交到 GitHub。发现泄露立即在服务商控制台撤销。

## 怎么获得（可选，免费额度可能变化）

- OpenAI：platform.openai.com 注册后创建 API key（需要充值小额余额才能调用，价格以官方页面为准）。
- Anthropic：console.anthropic.com 注册后创建 API key。
- 两家都有官方文档说明限额与价格；**本课不代管、不收集你的密钥**。

## 你刚才发生了什么（真实模式）

你在页面里做了一次最小规模的「程序调用模型」：

1. 浏览器把你的消息 + 一段系统指令打包成 JSON；
2. 通过 HTTPS POST 发到服务商官方端点（请求头里带着你的 key 做身份证明；Anthropic 还需要专门的浏览器直连许可头）；
3. 服务商验证 key、计费、让模型生成回复；
4. 页面把返回的回复、token 用量、耗时展示给你。

第 11 模块的核心实验，就是用 Python 把这四步写成循环、加上工具调用和停止条件——那就是一个最小的 Agent loop。你现在已经摸过它的地基。

## 风险、版本与来源卡片

- **费用**：真实调用按你的账户计费；离线演示免费。价格以官方页面为准，课程标注的价格都可能过时。
- **安全**：密钥只存浏览器内存，不写 localStorage、不发往课程服务器；本机开发者工具可见属正常现象（这也提醒你：任何让你输入密钥的网页都值得这样审视）。公共电脑勿用；用完可撤销。
- **核验**：OpenAI `chat completions` 端点与 Anthropic `messages` 端点的浏览器直连（含 `anthropic-dangerous-direct-browser-access` 头）于 2026-08-17 核验；模型名称变化很快，输入框里的默认值只是示例。
- **边界**：课程的 CI 只验证离线演示模式；真实调用属于你的现场验证，失败（密钥错、限流、断网）本身也是有价值的学习数据。
