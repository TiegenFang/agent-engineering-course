# W3 · API key 与第一次真实调用

前两课你只在网页内学习，零费用。本课第一次接触「程序世界的水电表」——API key，并跟着一个**贴着 token 标签的包裹**走完一次模型调用的全程。**不办密钥也能完成本课**（离线看已记录样例），真实调用是可选的付费增强。

## API key 是什么

API key 是一串像 `sk-abc123...` 的密钥，作用类似「带计费的钥匙」：

1. **证明是谁在调用**：服务商据此把请求记到你的账户。
2. **按用量扣费**：不是订阅制门票，而是水电表——用多少算多少。一次演示对话通常只花不到一分钱，但你要有这个意识。
3. **必须像钥匙一样保管**：泄露的 key 等于别人用你的水电表消费。公共电脑不输入、不截图、不把 key 发给任何人（包括 AI 对话框）、不提交到 GitHub。发现泄露立即在服务商控制台撤销。

## 请求之旅实验

下方实验把一次调用画成 7 帧旅程：**写好消息 → 打包贴标签 → 穿过 HTTPS 隧道 → 服务商大楼关卡（验钥匙 + 计费）→ 模型生成 → 回程包裹 → 拆包对表**。每一帧由你点击「下一帧」推进，不会自动播放；每一步的文字播报与图注同源，动画只解释概念、不模拟任何服务商界面。

它有两种模式：

- **离线样例（默认）**：零网络、零费用。你看到的是一份**已记录样例**——依据 OpenAI `chat completions` 与 Anthropic `messages` 官方文档的响应形状构造（2026-08-17），**待现场采集核验**，页面上明确标注「已记录样例，非此刻发出」。样例含请求端点、逐段注释、token 用量与耗时，可以点开查看完整响应 JSON 与每一段在干什么。**把旅程推进到最后一帧，本课即标记完成。**
- **真实调用**：输入你的密钥，浏览器**直接**连 OpenAI 或 Anthropic 官方接口。密钥只存浏览器内存，刷新即消失；课程站没有服务器，不可能收到它。调用成功后，动画会**回放你刚才那次调用的真实数字**（服务商、模型、输入/输出 token、耗时回填到包裹标签与关卡）。

没有密钥的继续路径：密钥随时可以在服务商控制台**撤销**，弄错了删掉重发一把就行；以后想真实调用时回到这一页即可。想现在就试的话，实验里的折叠侧栏有获取密钥的普通话分步说明（只外链官方页面，真实调用按你的账户计费）。

## 匿名调用摘要：成功会留下什么

真实调用**成功**时，页面会把一份**匿名摘要**保存在你的浏览器本地：服务商、模型、输入/输出 token、耗时、时间戳——仅此六个字段，**绝不含密钥与消息正文**。它兑现了 v2 承诺的「live call record」：刷新页面后，「上次真实调用摘要」仍能告诉你当时发生了什么，W4 回看时也有据可查。这份摘要和起步章进度一样只存在你的浏览器里，可随本地数据一并清除。

失败（密钥错、请求太快、断网）不会写摘要，但**失败本身也是有价值的实验数据**：错误分支动画会演示「包裹被关卡退回」或「包裹没能进入隧道」，并给出普通话解释——401/403 是密钥没复制完整或没权限，429 是请求太快或账户额度用完。

## 你刚才发生了什么

把 7 帧旅程翻译成工程语言，你在页面里做了一次最小规模的「程序调用模型」：

1. 浏览器把你的消息 + 一段系统指令打包成 JSON（第 1–2 帧）；
2. 通过 HTTPS POST 发到服务商官方端点，请求头里带着你的 key 做身份证明；Anthropic 还需要专门的浏览器直连许可头（第 3 帧）；
3. 服务商验证 key、计费、让模型生成回复（第 4–5 帧）；
4. 页面把返回的回复、token 用量、耗时展示给你，成功时另存一份匿名摘要（第 6–7 帧）。

第 11 模块的核心实验，就是用 Python 把这四步写成循环、加上工具调用和停止条件——那就是一个最小的 Agent loop。你现在已经摸过它的地基。

## 风险、版本与来源卡片

- **费用**：真实调用按你的账户计费；离线样例免费。价格以官方页面为准，课程标注的价格都可能过时。
- **安全**：密钥只存浏览器内存，不写 localStorage、不发往课程服务器；本机开发者工具可见属正常现象（这也提醒你：任何让你输入密钥的网页都值得这样审视）。公共电脑勿用；用完可撤销。
- **隐私**：匿名调用摘要只含服务商/模型/用量/耗时/时间戳六个字段，不含密钥与消息正文；只存于你的浏览器本地。
- **核验**：OpenAI `chat completions` 端点与 Anthropic `messages` 端点的浏览器直连（含 `anthropic-dangerous-direct-browser-access` 头）于 2026-08-17 核验；模型名称变化很快，输入框里的默认值只是示例。
- **样例边界**：离线样例依据官方文档响应形状构造（2026-08-17），**待现场采集核验**——数值为真实感构造值，不是某次真实调用的记录；现场采集替换前，页面始终标注「已记录样例，非此刻发出」。
- **边界**：课程的 CI 只验证离线样例模式与组件契约；真实调用属于你的现场验证，失败（密钥错、限流、断网）本身也是有价值的学习数据。
