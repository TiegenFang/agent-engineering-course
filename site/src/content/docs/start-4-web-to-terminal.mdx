# W4 · 从网页到终端：解锁进阶线

网页端起步章的前三课都在浏览器里完成。本课是这段旅程的最后一站：一张**分岔地图**收拢你的全部脚印——左边是你走过的「浏览器之路」，右边是通向进阶线的「终端之门」。本课说清楚跨出「从网页到终端」这一步能解锁什么、原地不动也并不丢人，然后把决定权交回给你。**集齐 W1、W2、W3 的三把完成钥匙，加上本页的理解检查（第四键），网页端起步章（W1–W4）收官**。

## 装了终端环境，能解锁什么

「终端环境」指在你自己的电脑上准备好 PowerShell 7、Python、Git 这些命令行工具，以及编辑器和账号。准备好之后，课程的进阶线会整体打开：

- **真实仓库实战**：进阶课的每个实验都发生在真实的代码仓库里——改文件、跑命令、看结果、留下提交记录，而不是在网页里模拟。网页学不会「命令失败后怎么办」，真实终端会逼你学会。
- **Codex 与 Claude Code**：本课主角的两位 Coding Agent 都运行在你的终端和本机仓库里。它们是「带工具上岗」的 Agent（W1 的那个循环），必须在终端环境里才能真正上岗。
- **检查器与可核验证据**：课程检查器 `course_check` 在你本机运行，验证实验结果并输出匿名 JSON 证据。证据可导入课程网页形成完成状态——网页端的打勾是「自我申报」，检查器的 JSON 才是「可核验成果」。

## 不装终端，也能继续学什么

不准备终端环境，你依然是这门课的合法学员：

- **全部阅读内容**：所有课节的正文、心智模型和案例都可以在浏览器（包括手机）阅读，无需任何安装。
- **W1–W3 的交互**：知识检查、离线演示、自带密钥的真实调用照常可用，随时回来复习。
- **概念复习**：模型、对话、工具、Agent 循环、API key 这些概念，够你读懂团队里 Agent 讨论的大半。

区别只有一个：**进阶线的实战（真实仓库、Coding Agent、检查器证据）需要终端环境**。阅读与概念不需要。

## 最小准备清单（Windows 11 + PowerShell 7）

本课不教安装步骤——那是[模块 0：环境诊断学习旅程](/module-0-environment/)的正式工作，它会带你逐项诊断、修复、复检。这里只给清单，让你知道要准备什么：

1. **Windows 11 + PowerShell 7.x**：课程主路径的终端与 Shell。
2. **Python 3.11+ 与 Git 2.x**：进阶实验的运行与版本控制基线。
3. **一个能从终端打开的编辑器**：如 VS Code 的 `code` 命令。
4. **GitHub 与至少一个 Coding Agent 账号**：由你本人确认可用，课程脚本不读取身份信息。

不满足也不必慌：模块 0 的诊断脚本会先告诉你哪一项缺失，再决定补什么。

## 分岔地图：脚印、钥匙与终端之门

地图左边三枚脚印对应 W1–W3：哪一课在你的浏览器里留了完成记录，脚印就点亮。右边那扇门要集齐**四把钥匙**——W1、W2、W3 的完成记录，加上本页「理解检查」全勾（本页确认）——才会亮起打开。缺哪把钥匙，地图会明确告诉你缺哪一课、附上跳转链接（例如「先去完成 W2」）。小循在门前把工具箱递给你：门一开，这一页的插画就功成身退，课程换回工程师的编辑排版，你也从「新手学员」切换为「准工程师」——风格随能力成长，正是这段旅程的收束方式。

进度只读取你浏览器里的本地记录：如果在别的标签页刚完成某一课，回到这里点一下「刷新脚印进度」即可看到脚印点亮。

地图下方是改进后的自评清单，分两组、性质不同：

- **理解检查（3 条，计入完成）**：确认你确实分清了终端、真实仓库与可核验证据这些概念——这是四键里「本页确认」那一把。
- **意愿自评（3 条，不计入完成）**：时间投入与环境准备的自我对照。没打勾不算「没完成」，只说明你或许想再等等；模块 0 不会因此拒绝你。
