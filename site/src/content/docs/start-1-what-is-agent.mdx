# W1 · 什么是 Agent：模型、对话、工具

本课不需要安装任何东西，全程在浏览器里完成。读完正文、答对知识检查，本课就算完成——结果保存在你自己的浏览器里。

## 一分钟版结论

- **模型**：一台「收到文字、生成文字」的引擎。它没有记忆、不会主动做任何事。
- **对话**：你和模型轮流发消息的过程。模型的「记忆」只是本次对话里能看到的文字。
- **工具**：模型外面的能力，比如查网页、改文件、调接口。模型自己只会生成文字，工具让文字变成动作。
- **Agent**：把上面三者连起来、围绕一个目标转的循环——**想 → 调工具 → 看结果 → 再决定下一步 → 直到完成或该停下**。

## 心智模型：实习生 + 工具箱

把模型想成一位「读过所有书但第一天上班」的实习生：知识渊博，但不了解你的项目，也没有你电脑的钥匙。

- 只跟他聊天（对话），他能给建议；
- 给他工具箱的钥匙（工具），他能替你查资料、改文件、跑命令；
- 而 Agent 是「带目标上岗」的实习生：你交代目标，他自己计划、动手、检查、修正——这就是这门课要教你的工作方式。

## 为什么这很重要

Codex 和 Claude Code 这类编程助手，本质都是「模型 + 工具 + 循环」的 Agent：模型负责想，工具负责做，循环负责把任务推进到可验证的完成状态。本课之后的每一章，都是在给这个骨架加上一块具体的能力。
