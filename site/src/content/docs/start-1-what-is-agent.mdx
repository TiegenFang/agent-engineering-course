# W1 · 什么是 Agent：模型、对话、工具

本课不需要安装任何东西，全程在浏览器里完成。学法是「先猜、再跑、再检查」：先答 2 道预测题，再把一条 Agent 循环跑道完整跑一圈，最后做 3 道可重做的知识检查。三件事都完成，本课就算完成——结果保存在你自己的浏览器里。

## 一分钟版结论

- **模型**：一台「收到文字、生成文字」的引擎。它没有记忆、不会主动做任何事。
- **对话**：你和模型轮流发消息的过程。模型的「记忆」只是本次对话里能看到的文字。
- **工具**：模型外面的能力，比如查网页、改文件、调接口。模型自己只会生成文字，工具让文字变成动作。
- **Agent**：把上面三者连起来、围绕一个目标转的循环——**想 → 调工具 → 看结果 → 再决定下一步 → 直到完成或该停下**。

## 心智模型：实习生 + 工具箱

把模型想成一位「读过所有书但第一天上班」的实习生：知识渊博，但不了解你的项目，也没有你电脑的钥匙。

- 只跟他聊天（对话），他能给建议；
- 给他工具箱的钥匙（工具），他能替你查资料、改文件、跑命令；
- 而 Agent 是「带目标上岗」的实习生：你交代目标，他自己计划、动手、检查、修正——这就是这门课要教你的工作方式。

## 动手环节：先猜，再跑一圈

概念读一遍容易「感觉懂了」。下面换一种验证方式：先把直觉押上去（预测），再到环形跑道上一站一站核对。跑道上有四个站点，对应 Agent 循环的每一步：

1. **收到输入**——这一圈要解决什么；
2. **生成输出**——模型「想」出下一步；
3. **调用工具**——真正动手，拿到结果；
4. **观察结果，决定继续或停止**——没完成就带着结果再跑一圈，停止条件满足就停下。

跑道由小循带队：每停一站，它会换一个姿势，并把这一站发生的事用普通话讲一遍。跑完全部四站，「完整跑过一圈」这项条件就达成了。

<h2 id="api-key-preview">一把带计费的钥匙（下一课预告）</h2>

知识检查里有两题和 **API key** 有关，先用三句话打个底：

- API key 是一串字符，作用像**一把带计费的钥匙**：证明「这次调用是你发起的」，并且每次开门（调用）都按用量扣费——所以它要像钥匙一样保管，泄露了就去服务商控制台撤销重发。
- 在下一课的实验页里，你的密钥**只存在浏览器内存**：课程站是静态页面，没有服务器可收密钥，请求直连模型服务商的官方端点。
- 不办密钥也能完成下一课：离线演示模式零网络、零费用。真实调用是可选的付费增强。

## 为什么这很重要

Codex 和 Claude Code 这类编程助手，本质都是「模型 + 工具 + 循环」的 Agent：模型负责想，工具负责做，循环负责把任务推进到可验证的完成状态。本课之后的每一章，都是在给这个骨架加上一块具体的能力。

## 版本与来源卡片

- 本课为原创概念内容，无需账号、无费用、无外部副作用；预测题、跑道与知识检查全部在浏览器本地运行，不发出任何网络请求。
