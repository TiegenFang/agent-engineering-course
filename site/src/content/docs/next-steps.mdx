## 先修关系说明

- **先学手写，再学框架**：模块 11 的最小 Agent loop 是所有框架主题的先修。没有手写过响应—工具—停止循环就学框架，容易把框架魔法当成协议本身。
- **迁移经验先于第二工具**：在学其他 Coding Agent 之前，先完成模块 3 的双工具迁移挑战，理解「能力目标相同、操作差异在哪」。
- **RAG 在上下文工程之后**：模块 5 的预算与压缩经验决定你在 RAG 里检索多少、塞多少；顺序颠倒容易做出无预算约束的堆料系统。
- **微调是最后手段**：只有当指令工程（模块 2）、上下文工程（模块 5）和评测（模块 12）都无法满足时，再考虑训练。
